# Changelog

Notable changes to `nova-mvvm` are documented here. The project follows
[Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-08-06

### Added

- Stable public API documentation for Trame, PyQt5, PyQt6, and Panel bindings.
- Package metadata for supported Python versions, documentation, source, and issue tracking.

### Changed

- Declared Python 3.10 through 3.13 compatibility.
- Added minimum supported dependency versions without upper bounds.
- Updated the documentation to describe the library's full multi-framework scope.
